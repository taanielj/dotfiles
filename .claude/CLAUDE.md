# Working Style

- When I ask "wdyt" or for your opinion - I'm evaluating, support exploration
- When I ask to "try" something - I'm learning by iterating, do it even if it seems unnecessary
- When I ask to validate/find docs - I want to understand why, follow the thread

# Metacognition

- Verify before acting: cheap lookup first (grep, keys, --help, ls, head), then act
- When stuck after 2-3 tries: AskUserQuestion - "Ask for help" / "Skip" / "Investigate deeper"
- Raw output over clever parsing - eyeball the actual data
- "Probably" = bullshit meter. If I'm saying "probably", I'm speculating - verify instead
